# Mostafa Mahmoud Portfolio
Open `index.html` in a browser. Add your CV at `assets/cv/Mostafa_Mahmoud_CV.pdf`.
Edit the `[Add ...]` placeholders in `index.html` (experience, projects, testimonials, certificates).
Skill levels are off by default; add `data-level="80"` to a `.chip` to show a bar.
The contact form needs a backend (Formspree, EmailJS, etc.) before it can send messages.
